# Addon MISRA de Cppcheck

Ces fichiers sont les dépendances Python de l’addon `misra.py`, téléchargées depuis le dépôt officiel de Cppcheck à la révision `2.21.0`, qui correspond à la version locale de Cppcheck.

- Source : https://github.com/cppcheck-opensource/cppcheck/tree/2.21.0/addons
- Licence : GPL-3.0-or-later, reproduite dans [`COPYING`](COPYING).

Ils ne constituent pas une preuve de conformité MISRA. L’addon libre vérifie seulement une partie des règles MISRA C:2012.
